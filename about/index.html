About me

rodrigo@digomorelli.com

Technical Game UI/UX Designer specialized in engineering user-centered, performant game interfaces. Leveraging 4+ years in game production and 10+ years of graphic design expertise, I own the end-to-end UI pipeline, from mapping out early user flows to engineering data-driven in-engine systems. I successfully shipped cross-platform titles like Zona Eleitoral (PC/Mobile) and Adventure of Samsara (PC/Consoles), published by Atari.

What I Deliver:

• UX Conception & Visual Design: Designing intuitive user flows, wireframes, and clickable prototypes using Figma. I establish strong information architecture and scalable design systems with Adobe Creative Suite to ensure user-centered experiences, applying heuristic evaluations and accessibility guidelines.

• UI Programming: Engineering responsive game interfaces in Unity (UGUI / Canvas, UI Toolkit) and C#, ensuring performant cross-platform layouts while implementing fluid motion design and micro-interactions via Unity Animator. I build robust component architectures, leveraging architectural patterns (Observer, SOLID, MVC/MVVM) for clean, data-driven UI implementation.

• Optimization & 2D Pipelines: Owning asset integration and the 2D pipeline while respecting memory budgets. I use the Unity Profiler for draw call reduction, asset optimization, and to ensure smooth performance across platforms.

• Cross-Discipline Agile Collaboration: Empowering cross-functional collaboration utilizing Jira, Confluence, Trello and Miro. I bridge the communication between artists, designers and programmers, translating creative intent into technical requirements to align expectations, solve roadblocks, and streamline the production pipeline.
